# 资源提取与替换说明

## 本包的发布范围

只注册本包 `data/roster.json` 中的替换资源。兰斯、香姬、山本五十六的娘化资源不发布；以后重建时仍由 `release_scope.json` 排除。冈使用中文显示名“冈”。角色与势力归属见 `factions.json`，逐个包内位置的精确绑定见同目录 CSV 和 JSON。

## 提取游戏资源

公开仓库不包含原版图片和剧本快照。先按根目录 README 安装 Pillow，并从上游获取 alice-tools 放到 tools/。网页对照及剧本搜索均读取你自己提取的本机内容；提取时已安装其他 MOD，显示的也会是当时的资源。

双击根目录 `启动安装器.bat`，选择自己的游戏安装目录。点击“资源解压与浏览”→“解压游戏资源与剧本”。必须包含 rance7GA.ald、rance7GM.ald 和 rance7.ain；若存在 rance7GB.ald 也会读取。

工具只读取游戏文件，每次写入新的 `build/extracted-时间/`。ALD 成员解出原生 QNT/AJP，再用 `tools/alice.exe` 转为 PNG 并核对尺寸；AIN 提取 MSG0 消息、STR0 字符串及函数引用。只有全部成功后才切换当前浏览与搜索工作区。

也可使用命令行（Python 3.10+、Pillow）：

```powershell
python resource_tool.py --game "D:\Games\Sengoku Rance" --workspace "D:\ModWork\new-extraction" extract --workers 8
```

工作区应为新目录，已有 manifest.json 时拒绝重复解压，保护编辑文件。

| 工作区路径 | 内容 |
|---|---|
| originals/graphics/ | 原生 QNT/AJP 成员 |
| originals/archive_structure/ | ALD 索引、成员头、填充、页脚 |
| editable/graphics/ | 可编辑 PNG |
| editable/text/steam_current/messages/ | 消息分块 JSON |
| editable/text/steam_current/strings/ | 字符串分块 JSON |
| editable/text/steam_current/by-function-reference.txt | 函数与文本编号参考 |
| manifest.json | 来源包、指针、资源编号、尺寸与哈希 |

## 用发布安装器替换

退出游戏，先“检测状态”，展开势力后核对头像及战斗形象对比，再勾选武将或势力并安装。勾选一个武将包括本包登记的全部表情、动作、立绘及跨包物理位置。分组默认折叠。

安装器读取游戏原成员作为模板，保留 QNT 版本与坐标，按 PNG 重新编码；AJP 必须保留原透明遮罩。重建 ALD 后校验修改成员以及未修改成员、头字段、指针、共享别名、链接和页脚。备份完成后暂存并替换；失败时回滚。报告与备份记录在 build/ 中，可使用“从备份恢复”。格式与哈希校验不能代替启动游戏检查。

“导出选中角色／势力包”复制所选资源、绑定关系、说明、网页和工具，生成可独立运行的 ZIP。不会把解压工作区、游戏原包、备份或本机设置放入 ZIP。

## 如何读绑定关系

武将中文名用于显示，角色 ID 保持稳定。逻辑资源编号不是物理指针；同名文件可能同时存在于 GA 与 GM，两处都需记录。绑定表包含势力、角色 ID、来源包、原生文件名、指针、资源编号、共享别名、尺寸、差分、替换路径及 SHA-256。`data/roster.json` 是安装的实际名单，不以 CSV 编辑结果替代。

脚本 `nn` 和 `n名前` 可提供图片编号与名字编号的映射；CG 候选只表示剧情关联，必须查看图像确认人物。发布绑定采用替换记录及已确认关系，不自动把相似名字或候选 CG 作为确定人物。

## 制作自己的替换

在新解压工作区编辑 PNG，保留路径、画布尺寸、RGBA 和格式规则。头像需核对原图眼睛、脸部大小及下巴行，小头像保留边框和透明遮罩。文字只编辑分块 JSON 的 text，保留 id 与 original；TXT 为参考文件。

扫描与构建都只写工作区，不自动安装：

```powershell
python resource_tool.py --workspace "D:\ModWork\new-extraction" scan
python resource_tool.py --workspace "D:\ModWork\new-extraction" build --output "D:\ModWork\new-extraction\build\patch-output"
```

新素材若要加入发布安装器，应先在开发项目确认人物与物理位置、备份原图并登记 replacements.json，再重建发布版。不要只覆盖 `data/after`：安装器会核对注册 SHA-256。

公开仓库提供可独立运行的资源工具，开发项目的 mods/ 与原始资源库不随仓库发布。自行制作时可以直接使用上面的提取、scan、build 流程；构建出的 build/patch-output/install/ 是本机生成的完整资源包，请保留在本机，分享时只发布自己的替换素材与绑定说明。先备份对应游戏包，再将 install/ 中需要的文件复制到游戏目录，并启动游戏验证；其他版本需自行适配编号、包位置和格式。
