# 准备 alice-tools

从上游官方 Releases 下载 Windows 命令行版本：

https://github.com/nunuhara/alice-tools/releases

解压后，将 alice.exe 和下载包要求的依赖文件一起放在此目录，使 `tools/alice.exe` 存在。保留下载包内的许可证。可以在项目根目录用 `tools\alice.exe --help` 检查是否能运行。
