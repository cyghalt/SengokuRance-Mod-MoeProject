每组角色按行排列，列为立绘、大头像、战斗待机，每列内部左侧原图、右侧替换资源。缺失项保留空位并标注“暂无替换素材”，没有额外生成图片。

图片直接取自当前发布版资源，并校验替换素材和原图备份哈希。展示时裁去透明空白、等比缩放以便看清，不改变原生安装素材。战斗图属于静态动作资源，本组宣传图不是动画或游戏录屏。

马场彰炎新增的待机与攻击图已同步至发布版，当前名单为 45 位角色、404 个来源位置。页面截图为制作宣传图时的界面记录；当前公开版不附带原图预览，需提取自己的游戏资源后显示本机对照。

宣传图在 Git 仓库 main 分支中保存，可直接通过 README 的相对路径展示。普通 CG 会陆续替换，NSFW 内容基本不做，不反对二次开发和资源替换。
